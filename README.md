# Re:Grow | 고추 농사의 다음을, 함께

모바일 중심의 고추 재배 도우미 시제품입니다.

## 주요 기능

- 전국 시·도, 시·군·구와 시 산하 행정구 검색
- 주간 캘린더에서 매일의 최저·최고 기온, 날씨, 작물 상태와 메모 기록
- 병해충·생육 증상 직접 입력 및 기록
- 시·군·구별 현장 문제 지도와 제보
- 최근 검색, 농장 지역, 병해충·생육·기온 기록을 바탕으로 종자 비교 조건과 검색어 추천
- 기록과 비슷한 현장 경험을 찾는 검색형 상담

## GitHub Pages 게시

저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main`, `/(root)`를 선택하세요. 이 저장소가 공개 상태이면 웹사이트도 인터넷에 공개됩니다.

## 데이터와 추천의 범위

농장 설정, 검색 기록, 하루별 생육·기온, 증상과 상담 내역은 각 브라우저의 로컬 저장소에 저장됩니다. 사용자 간이나 기기 간 자동 공유는 되지 않습니다. 종자 추천은 기록에서 비교 기준과 검색어를 만드는 시제품이며, 특정 품종의 성능을 보증하지 않습니다. 실제 품종명을 추천하려면 최신 종자 카탈로그와 지역 실증 자료 연결이 필요합니다. 상담도 외부 대규모 언어모델이 아닌 기록 유사도 검색을 사용합니다.

지도 타일은 OpenStreetMap, 지도 화면은 Leaflet을 사용합니다. 지리 경계 데이터는 아직 연결되지 않았습니다.
