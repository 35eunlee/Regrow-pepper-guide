# Re:grow | 내 손안의 고추 농사

모바일 중심의 고추 재배 도우미 시제품입니다.

## 포함 기능

- 전국 시·도, 시·군·구, 일반구 268개 지역 검색
- 지역별 현장 문제 등록과 유형별 집계
- 사용자가 위치 공유에 동의한 제보를 표시하는 Leaflet 지도
- 이 기기에 저장한 제보를 검색해 유사 사례를 찾아주는 기록 검색형 상담
- JSON으로 제보 기록 내보내기와 가져오기

## GitHub Pages로 게시

1. 저장소 **Settings → Pages**로 이동합니다.
2. **Deploy from a branch**를 선택합니다.
3. 브랜치 `main`, 폴더 `/(root)`를 고르고 저장합니다.

이 저장소는 공개 상태이므로 GitHub Pages로 게시하면 사이트도 인터넷에 공개됩니다.

## 시제품의 저장·AI 범위

현장 기록, 농장 설정, 상담 내역은 브라우저의 로컬 저장소에만 저장됩니다. 서로 다른 사용자나 기기 사이에 자동으로 합쳐지지 않으며, JSON 파일로만 옮길 수 있습니다. 상담은 현재 외부 LLM을 호출하지 않고, 입력한 문장과 저장된 기록의 단어 유사도를 비교합니다. 공용 데이터베이스, 실제 생성형 AI, 행정구역 경계 폴리곤은 별도 서버와 데이터 연결이 필요합니다.

지도 타일은 OpenStreetMap, 지도 화면은 Leaflet을 사용합니다. 외부 네트워크 연결이 차단되면 지도 타일이 표시되지 않을 수 있습니다.
